# ADR-025: Theme 07-food — Inline Acceptance Criteria

## Status

**Superseded** by [ADR-041](../../../../docs/architecture/adr-041-colocated-docs-and-external-tracking.md) — 2026-08-01.

## What it decided

That the food theme would carry acceptance criteria inline in each PRD rather than in separate `us-NN-slug.md` user-story files, and recorded the deviation so other themes could choose to follow or diverge.

## Why it no longer holds

Both options it weighed are gone. PRDs, themes, user stories and acceptance-criteria checkboxes were all abolished: how a thing works lives in a README beside the code, decisions live in ADRs, and undone work lives in Huly. There is no longer a document for criteria to be inline in.

Stubbed deliberately: it described a choice within a documentation model the repo no longer uses, and read as current guidance.
